All build configuration has been consolidated into ``pyproject.toml``.
``setup.cfg``, ``setup.py``, and ``mypy.ini`` have been removed.
The package is now built with an in-tree PEP 517 build backend, ``lsst_versions._build_backend``, which writes the version file before delegating to ``setuptools.build_meta``.
This replaces the ``setup.py`` bootstrap that was needed because the ``setuptools`` entry point provided by this package is only available once the package is installed.
